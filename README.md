### 👨💻 About Me

- 🤖 **Agentic AI & Multi-Agent Workflows:** Architecting autonomous agents using **ReAct**, **Chain-of-Thought (CoT)**, human-in-the-loop safety guards, and voice multimodal interfaces.
- ⚡ **Distributed Asynchronous RAG:** Building high-concurrency RAG architectures decoupled with **Redis Queue (RQ)**, **Qdrant Vector Database**, and **Groq LPU** inference.
- 🧠 **Hybrid Memory & GraphRAG:** Engineering tri-layer persistent memory systems combining vector semantic search (**Mem0 + Qdrant**), structured **Neo4j Knowledge Graphs**, and automated **Belief Revision / Conflict Resolution**.
- 🌱 **Continuous Learning:** Exploring advanced **LangGraph multi-agent orchestration**, self-corrective RAG, and low-latency local inference.
- 💬 Ask me about: **Agentic AI, RAG Systems, Vector Databases, GraphRAG, Python, FastAPI, and React**.
- ⚡ Fun fact: **I love turning complex distributed AI workflows into clean, intuitive, and production-ready systems.**
